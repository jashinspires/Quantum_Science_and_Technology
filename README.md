# Quantum Science & Technology — Exam Study Guide

An offline-ready study website built for **Quantum Science and Technology (231EE7O04)** exam preparation. It organizes all 107 Mid-1 and Mid-2 questions into 19 progressive stages with structured 2-mark and 5-mark answers, formulas, and diagrams sourced directly from class notes.

## What's Inside
- **`1unit qst/` – `5 unit qst/`**: Original lecture slides, notes, and diagrams across Units 1 to 5.
- **`src/`**: React + TypeScript web app featuring Study Order and Unit-wise views, live search, mark filters, progress tracking, and practice mode.
- **`offline-study/`**: Standalone offline bundle (`index.html`, `style.css`, `script.js`) that runs directly in any browser without a server.
